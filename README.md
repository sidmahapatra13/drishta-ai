## How To Work In This Repo

1. Clone the repo.
2. Pull the latest `main` before starting work.
3. Create a branch for your task.
4. Make focused commits with clear messages.
5. Open a pull request when your work is ready.
6. Ask at least one teammate to review before merging.
7. Delete merged branches once they are no longer needed.

Branch name examples:

- `frontend/login-screen`
- `backend/user-api`
- `ai/model-prototype`
- `docs/pitch-outline`
- `design/wireframes`

## Team Workflow

- Use issues or a shared task list to track work.
- Keep PRs small enough to review quickly.
- Add screenshots or screen recordings for UI changes.
- Mention setup steps, environment variables, or migrations in the PR.
- Do not commit secrets, API keys, tokens, datasets with private data, or generated build folders.
- If something breaks `main`, fix it immediately or revert the change.
